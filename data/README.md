Runtime data is created here.

- stations.json — STANOX -> WGS84 map
- public_rail_geo.json — cached broad public rail geography fallback
- corpus.json — Network Rail CORPUS cache
- smart.json — Network Rail SMART berth-step cache
- naptan_rail.json — DfT NaPTAN rail coordinate cache
- schedule.sqlite — locally indexed Network Rail SCHEDULE/VSTP data

The distributed ZIP intentionally contains no credentials.
