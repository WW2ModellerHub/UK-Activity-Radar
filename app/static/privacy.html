Prototype privacy & product data

UK Activity Radar v1.0 is a local prototype. It does not contain an account system or payment system.

Saved in your browser

Map mode, watch zones, followed activity IDs and an anonymous random session token are stored in browser local storage. Watch-zone coordinates stay in the browser.

Prototype product analytics

The local backend stores a small whitelist of anonymous product events such as “search used”, “follow action”, “watch zone added”, or “pricing interest”. It stores the anonymous session token and a coarse feature label only. It deliberately does not store search text, precise location, watch-zone coordinates, activity IDs, email addresses or payment information.

External data

The live map calls the configured public/open transport and incident sources through the backend and uses public mapping/context services described in the project README. External links open the relevant provider in a new tab.

Before public launch

A public deployment should add a production privacy policy, secure admin access for aggregate analytics, rate limiting, a proper consent decision for analytics, and a review of every upstream data/tiles licence and usage policy.
